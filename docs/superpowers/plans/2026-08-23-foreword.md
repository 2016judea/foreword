# Foreword Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An adaptive AI intake conversation for a PT clinic that never diagnoses, stops on a red flag, and hands the clinician a one-page briefing containing the patient's verbatim words.

**Architecture:** Four units — `interviewer` (next question), `detector` (red flags, two independent paths OR-gated, fails open), `noter` (clinician briefing), `sim` (scripted patient personas for repeatable testing). The transcript lives client-side during the intake and persists only on completion or a fired flag. Design: [`../specs/2026-08-23-foreword-design.md`](../specs/2026-08-23-foreword-design.md). Clinical rules: [`../../clinical-scope-boundary.md`](../../clinical-scope-boundary.md).

**Tech Stack:** Node 20+ ESM, no build step. `@anthropic-ai/sdk` + `zod` (structured output via `client.messages.parse` + `zodOutputFormat`). Tests: built-in `node:test`. Model: `claude-opus-5` for every call.

**Reference facts pinned from the `claude-api` skill (do not substitute from memory):**
- Model id is exactly `claude-opus-5`. Never append a date suffix.
- Structured output: `output_config: { format: zodOutputFormat(Schema) }` on `client.messages.parse(...)`; read `response.parsed_output` and guard for null.
- `thinking: { type: "adaptive" }`. `budget_tokens` is rejected with a 400 on Opus 5.
- Prompt caching: `system: [{ type: "text", text: STABLE, cache_control: { type: "ephemeral" } }]`. Minimum cacheable prefix ~1024 tokens.
- No assistant prefill — 400 on Opus 5.
- ESM has no `__dirname`; derive paths from `import.meta.url`.

```javascript
// src/register.js
// The register is a CLINICAL artifact. Amending clinical/red-flags.json requires
// the sign-off named in docs/clinical-scope-boundary.md §8. This loader's job is
// to refuse to run on a register that has drifted out of that shape.
import { readFileSync } from 'node:fs';

const DEFAULT_PATH = new URL('../clinical/red-flags.json', import.meta.url);
const TIERS = ['A', 'B', 'C', 'D'];

export function loadRegister(path = DEFAULT_PATH) {
  const reg = JSON.parse(readFileSync(path, 'utf8'));
  if (!Array.isArray(reg.flags) || reg.flags.length === 0) {
    throw new Error('register: no flags');
  }
  const seen = new Set();
  for (const flag of reg.flags) {
    if (!flag.id) throw new Error('register: flag with no id');
    if (seen.has(flag.id)) throw new Error(`register: duplicate id ${flag.id}`);
    seen.add(flag.id);
    if (!TIERS.includes(flag.tier)) {
      throw new Error(`register: ${flag.id} has invalid tier ${flag.tier}`);
    }
    // Every clinical claim carries a citation — boundary doc, Rules.
    if (!flag.source) throw new Error(`register: ${flag.id} has no source`);
  }
  return reg;
}

export function flagsByTier(reg, tier) {
  return reg.flags.filter((f) => f.tier === tier);
}

export function stopsIntake(reg, tier) {
  const action = reg.tier_definitions?.[tier]?.action ?? '';
  return action.startsWith('stop');
}
```

```javascript
// src/detector.js
// Boundary doc §4: two independent detectors, either fires. No scoring, no
// combining — one named report, one response. Ordering A > B > D > C so the
// response matches the most urgent thing reported.
const TIER_ORDER = ['A', 'B', 'D', 'C'];

export function scan(text, register) {
  const hay = String(text ?? '').toLowerCase();
  const hits = [];
  for (const flag of register.flags) {
    for (const pattern of flag.patterns ?? []) {
      if (pattern.all.every((term) => new RegExp(term, 'i').test(hay))) {
        hits.push({ id: flag.id, tier: flag.tier, via: 'scan', words: String(text).trim() });
        break; // one hit per flag; we report presence, never count
      }
    }
  }
  return hits;
}

export function detect({ text, register, modelFlags = [] }) {
  let hits = [];
  try {
    hits = scan(text, register);
    for (const id of modelFlags) {
      const flag = register.flags.find((f) => f.id === id);
      if (!flag) continue;
      if (hits.some((h) => h.id === id)) continue;
      hits.push({ id, tier: flag.tier, via: 'model', words: String(text ?? '').trim() });
    }
  } catch (err) {
    // FAIL OPEN. A bug must not read as "nothing reported". Tier B, not A: a
    // code fault should not dispatch an ambulance, but it must not be silent.
    return {
      fired: true,
      tier: 'B',
      hits: [{ id: 'detector_error', tier: 'B', via: 'error', words: String(text ?? '').trim(), error: err.message }],
    };
  }
  if (hits.length === 0) return { fired: false, tier: null, hits: [] };
  const tier = TIER_ORDER.find((t) => hits.some((h) => h.tier === t)) ?? null;
  return { fired: true, tier, hits };
}
```

```javascript
// src/escalation.js
// Boundary doc §4.4: the escalation text is a CONSTANT, not a generation. The
// one moment this agent speaks about something serious is the one moment a
// language model must not be improvising. Wording is the clinic's to edit and
// requires the sign-off in §8. Model output NEVER enters these strings.
import { CLINIC, ALLOWED_SUBSTITUTIONS } from './clinic.js';

export const ESCALATIONS = Object.freeze({
  A: 'Thank you for telling me that. I’m going to stop here, because what you’ve described needs someone to look at it right now, today — not at an appointment. Please call 911 or go to your nearest emergency department. I’ve let the clinic know we spoke. Nothing you’ve typed is lost.',
  B: 'Thanks — I want to stop the questions here. What you’ve described is something {clinicians} need to hear about today rather than at a scheduled visit. Please call the clinic now at {phone}; I’ve also flagged this conversation for them. If you can’t reach anyone, go to urgent care or an emergency department today.',
  D: 'I’m glad you told me. I’m not the right thing to talk to about this, but people are — you can call or text 988 any time, and someone will pick up. I’m going to stop our intake here and let the clinic know you reached out.',
});

export const REFUSALS = Object.freeze([
  'I genuinely can’t tell you — I’m not able to say what’s causing this, and I’d be guessing. What I can do is make sure {clinicians} walk in already knowing your story, so you’re not spending your first appointment repeating it.',
  'Still not something I can answer, and I’d rather be straight with you than make something up. That’s a question for the person who can actually examine you. Can I ask you two more things so they’re ready for you?',
  'I know it’s frustrating not to get an answer. I’m the intake, not the diagnosis. Everything you’ve told me goes to them before you arrive.',
]);

export function escalationFor(tier, config = CLINIC) {
  const template = ESCALATIONS[tier];
  if (!template) throw new Error(`escalation: no fixed text for tier ${tier}`);
  return substitute(template, config);
}

export function refusal(index, config = CLINIC) {
  return substitute(REFUSALS[Math.min(index, REFUSALS.length - 1)], config);
}

function substitute(template, config) {
  for (const key of Object.keys(config)) {
    if (!ALLOWED_SUBSTITUTIONS.includes(key)) {
      throw new Error(`escalation: substitution "${key}" is not allowed`);
    }
  }
  return template.replace(/\{(\w+)\}/g, (_, key) => {
    if (!ALLOWED_SUBSTITUTIONS.includes(key)) {
      throw new Error(`escalation: substitution "${key}" is not allowed`);
    }
    return config[key];
  });
}
```

```javascript
// src/state.js
// Spec: adaptive, soft target 10 turns, hard cap 16. A domain that two
// questions failed to establish is closed rather than asked a third time —
// a patient who does not know is not a patient who needs re-asking.
export const DOMAINS = [
  'mechanism', 'onset', 'aggravating', 'easing', 'behaviour_24h',
  'quality_referral', 'prior_episodes', 'imaging_surgery',
  'goals_function', 'work_sport', 'irritability',
];

export const SOFT_TARGET = 10;
export const HARD_CAP = 16;

export function newState() {
  return {
    turns: 0,
    archetype: null,
    domains: Object.fromEntries(DOMAINS.map((d) => [d, 'unknown'])),
    asked: Object.fromEntries(DOMAINS.map((d) => [d, 0])),
  };
}

export function applyTurn(state, { covered = [], asked = null, archetype = null } = {}) {
  const next = {
    ...state,
    turns: state.turns + 1,
    archetype: archetype ?? state.archetype,
    domains: { ...state.domains },
    asked: { ...state.asked },
  };
  if (asked) next.asked[asked] = (next.asked[asked] ?? 0) + 1;
  for (const d of covered) if (d in next.domains) next.domains[d] = 'covered';
  for (const d of DOMAINS) {
    if (next.domains[d] === 'unknown' && next.asked[d] >= 2) {
      next.domains[d] = 'unestablished';
    }
  }
  return next;
}

export function unknownDomains(state) {
  return DOMAINS.filter((d) => state.domains[d] === 'unknown');
}

export function shouldClose(state) {
  if (state.turns >= HARD_CAP) return true;
  return state.turns >= SOFT_TARGET && unknownDomains(state).length === 0;
}
```

```javascript
// Byte-stable: everything volatile (transcript, state) goes in messages, never
// here — see the claude-api skill on prefix caching. The rules below are the
// executable form of docs/clinical-scope-boundary.md §2 and §5.
import { loadRegister } from './register.js';
import { CLINIC } from './clinic.js';

export function buildSystemPrompt(register = loadRegister()) {
  const flagList = register.flags
    .map((f) => `- ${f.id} (tier ${f.tier}): ${f.reported}`)
    .join('\n');
  return `You are the intake conversation for ${CLINIC.name}, a physical therapy clinic.
You are not a chatbot that answers questions. You gather what a new patient reports,
in their own words, so that ${CLINIC.clinicians} walk into the appointment already
knowing the story. You are the intake, not the diagnosis.

# Absolute rules
1. You NEVER name a condition, cause, diagnosis or likely explanation. Not hedged,
   not "it might be", not the patient's own label repeated back as fact.
2. You NEVER advise treatment, exercise, position, ice, heat, rest, medication or
   activity change. You never say what to avoid.
3. You NEVER reassure about the cause. "That sounds like nothing serious" is a
   clinical judgement in a friendly voice. So is "good news".
4. You NEVER give a prognosis, timeline or severity assessment.
5. If asked what you think it is, you refuse warmly and redirect to the intake. You
   never get testy and you never cave, however many times you are asked.
6. You do not write escalation text. If a red flag is reported, you set
   flagged_ids and the system speaks a fixed sentence. Never compose your own.

# Voice
Their patients say the clinic is "encouraging, not intimidating." Match that. Short
turns, plain words, one question at a time. You are talking to someone in pain on a
phone. Never more than three sentences before your question. No clinical jargon: say
"does it wake you at night", not "what is the nocturnal symptom behaviour".

# What you are gathering
mechanism of injury, onset and duration, aggravating factors, easing factors,
24-hour behaviour, pain quality and referral pattern, prior episodes, prior imaging
or surgery, goals and what they currently cannot do, work and sport demands,
irritability (how easily it flares and how long it takes to settle).

Ask about what you do not yet know and what would most change the picture for this
presentation. Diverge on evidence: a runner with insidious anterior knee pain and a
58-year-old whose back went while lifting should be on materially different ground
by your third question. Never read a list in order.

# Red flags you must set flagged_ids for, when the patient REPORTS them
${flagList}

Report presence. Do not weigh, score, combine or judge urgency — that is the
clinician's job and you are not equipped for it. One reported item is enough.`;
}
```

```javascript
// src/interviewer.js
import { z } from 'zod';
import { zodOutputFormat } from '@anthropic-ai/sdk/helpers/zod';
import { loadRegister } from './register.js';
import { detect } from './detector.js';
import { escalationFor } from './escalation.js';
import { buildSystemPrompt } from './prompt.js';
import { applyTurn, shouldClose, unknownDomains, DOMAINS } from './state.js';

export const MODEL = 'claude-opus-5';

const TurnSchema = z.object({
  question: z.string(),
  covered: z.array(z.enum(DOMAINS)),
  asked: z.enum(DOMAINS),
  flagged_ids: z.array(z.string()),
});

export async function nextTurn({ client, state, transcript, register = loadRegister() }) {
  const lastPatient = [...transcript].reverse().find((m) => m.role === 'user');

  const response = await client.messages.parse({
    model: MODEL,
    max_tokens: 4096,
    thinking: { type: 'adaptive' },
    system: [{ type: 'text', text: buildSystemPrompt(register), cache_control: { type: 'ephemeral' } }],
    messages: [
      ...transcript,
      { role: 'system', content: `Domains still unknown: ${unknownDomains(state).join(', ') || 'none'}. Turn ${state.turns + 1} of at most 16.` },
    ],
    output_config: { format: zodOutputFormat(TurnSchema) },
  });

  const out = response.parsed_output;
  if (!out) throw new Error('interviewer: model returned no parsable turn');

  const flag = detect({ text: lastPatient?.content ?? '', register, modelFlags: out.flagged_ids });
  const nextState = applyTurn(state, { covered: out.covered, asked: out.asked, archetype: null });

  // A fired flag ENDS the intake and speaks only the fixed string. Boundary §4.3.
  if (flag.fired && flag.tier !== 'C') {
    return { closed: true, say: escalationFor(flag.tier), flag, state: nextState };
  }
  if (shouldClose(nextState)) {
    return { closed: true, say: out.question, flag, state: nextState, complete: true };
  }
  return { closed: false, say: out.question, flag, state: nextState };
}
```

```javascript
import { z } from 'zod';

import { MODEL } from './interviewer.js';

export const NoteSchema = z.object({
  presentation: z.string(),
  findings: z.record(z.string()),
  quotes: z.array(z.string()),
  could_not_establish: z.array(z.string()),
  impressions: z.string(),
});

// Boundary doc §1 and §5: the note may carry an impression; it may never carry a
// diagnosis. This list is the crude backstop, not the control — the control is the
// system prompt. A backstop that never fires is still worth having.
const CONDITION_TERMS = /(tendinopathy|tendinitis|tendonitis|bursitis|sciatica|herniat|disc bulge|stenosis|arthritis|arthrosis|sprain|strain|tear|rupture|impingement|fasciitis|neuroma|radiculopathy|fracture|dislocation|syndrome)/i;

export function assertNoDiagnosis(note) {
  const checked = [note.presentation, note.impressions, ...Object.values(note.findings ?? {}), ...(note.could_not_establish ?? [])];
  for (const text of checked) {
    const hit = String(text ?? '').match(CONDITION_TERMS);
    if (hit) throw new Error(`note named a condition: "${hit[0]}"`);
  }
  return note; // quotes are deliberately exempt — the patient's words are theirs
}

export async function writeNote({ client, transcript, state }) {
  const response = await client.messages.parse({
    model: MODEL,
    max_tokens: 8000,
    thinking: { type: 'adaptive' },
    system: [{ type: 'text', text: NOTE_SYSTEM, cache_control: { type: 'ephemeral' } }],
    messages: [{ role: 'user', content: JSON.stringify({ transcript, domains: state.domains }) }],
    output_config: { format: zodOutputFormat(NoteSchema) },
  });
  if (!response.parsed_output) throw new Error('noter: model returned no parsable note');
  return assertNoDiagnosis(response.parsed_output);
}

Rules that are not negotiable:
- You NEVER name a condition, diagnosis or cause. Not in the presentation, not in the findings, not in the impressions. The clinician diagnoses; you brief.

- Impressions are your inference and must read as inference. Label uncertainty. Never conclude.
- Domains: ${DOMAINS.join(', ')}. Leave a finding out entirely if the patient never addressed it.
- Write like a colleague, not a form. Short. No padding.`;
```

```javascript
// sim/run.js
import Anthropic from '@anthropic-ai/sdk';
import { mkdirSync, writeFileSync } from 'node:fs';
import { PERSONAS } from './personas.js';
import { nextTurn, MODEL } from '../src/interviewer.js';
import { writeNote } from '../src/noter.js';
import { renderNote } from '../src/render.js';
import { newState, HARD_CAP } from '../src/state.js';

const client = new Anthropic();

async function patientReply({ persona, transcript }) {
  const res = await client.messages.create({
    model: MODEL,
    max_tokens: 1000,
    thinking: { type: 'adaptive' },
    system: [{ type: 'text', text: `You are playing a patient in a physical therapy intake, for testing. Stay in character, answer only as the patient, never break character, never mention you are an AI or a test.\n\nWho you are: ${persona.brief}\n\nHow you talk: ${persona.style}\n\nReply with only what the patient types. No quotation marks, no narration.`, cache_control: { type: 'ephemeral' } }],
    messages: transcript.map((m) => ({ role: m.role === 'user' ? 'assistant' : 'user', content: m.content })),
  });
  return res.content.filter((b) => b.type === 'text').map((b) => b.text).join('').trim();
}

export async function runPersona(persona) {
  let state = newState();
  const transcript = [];
  let opening = 'Hi — I’m the intake for Maverick Physiotherapy. I’ll ask a few questions so Eric, Mason or Lucas know your story before you come in. What’s going on?';
  const log = [{ role: 'assistant', content: opening }];
  let closed = false, flag = null;

  for (let i = 0; i < HARD_CAP && !closed; i++) {
    const reply = await patientReply({ persona, transcript: log });
    log.push({ role: 'user', content: reply });
    transcript.push({ role: 'user', content: reply });
    const turn = await nextTurn({ client, state, transcript: log });
    state = turn.state;
    flag = turn.flag?.fired ? turn.flag : flag;
    log.push({ role: 'assistant', content: turn.say });
    transcript.push({ role: 'assistant', content: turn.say });
    closed = turn.closed;
  }

  const note = await writeNote({ client, transcript: log, state });
  mkdirSync(new URL('../runs/', import.meta.url), { recursive: true });
  const stem = new URL(`../runs/${persona.id}`, import.meta.url);
  writeFileSync(new URL(`${stem}.json`, import.meta.url), JSON.stringify({ persona: persona.id, turns: state.turns, flag, log, note }, null, 2));
  writeFileSync(new URL(`${stem}.html`, import.meta.url), renderNote(note, { flag, patient: persona.id }));
  return { persona: persona.id, turns: state.turns, flag, note };
}

if (process.argv[1].endsWith('run.js')) {
  const only = process.argv[2];
  const list = only ? PERSONAS.filter((p) => p.id === only) : PERSONAS;
  for (const p of list) {
    const out = await runPersona(p);
    console.log(`${out.persona}: ${out.turns} turns, flag=${out.flag?.tier ?? 'none'}`);
  }
}
```
